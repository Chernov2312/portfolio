# Code Tester MCP

MCP-сервер предоставляет инструменты для изучения Python-проекта, генерации pytest-тестов и рефакторинга текста или кода. Генерацию выполняет локальная модель через OpenVINO Model Server (OVMS).

## Какую проблему решает проект

При работе с незнакомым Python-проектом разработчику или AI-ассистенту приходится вручную искать нужные файлы, собирать контекст и готовить тестовую инфраструктуру. Создание API-тестов также требует учитывать существующие фикстуры, настройки pytest и схемы ответов.

Code Tester MCP связывает проект с AI-ассистентом через инструменты для чтения структуры и файлов, подготовки `conftest.py`, генерации API-тестов с Pydantic-схемами и рефакторинга. Это сокращает рутинную подготовку и помогает создавать тесты с учётом контекста проекта. Для генерации используется локальная модель через OVMS, поэтому при локальной настройке исходный код можно обрабатывать без отправки во внешний AI-сервис.

## Как устроено

- `mcp/main.py` запускает MCP-сервер с транспортом Streamable HTTP.
- `mcp/submcp/project_settings.py` предоставляет чтение структуры и файлов проекта.
- `mcp/submcp/code_test.py` генерирует `conftest.py`, API-тесты и файл Pydantic-схем.
- `mcp/submcp/code_refactor.py` возвращает отрефакторенный текст; сам файл инструмент не меняет.
- `mcp/orchestrator.py` — отдельный CLI-клиент: отправляет запрос OVMS, передаёт модели MCP-инструменты, выполняет выбранные вызовы и показывает результат.

Оркестратор — **MCP-клиент**, а не MCP-сервер. Для подключения Codex к инструментам проекта указывай HTTP endpoint сервера, а не запускай `orchestrator.py` как stdio-команду.

## Требования

- Windows 10/11 или Linux с Docker Compose.
- Python 3.13 для локального запуска оркестратора.
- OpenVINO Model Server с загруженной моделью.
- OVMS должен быть доступен на порту `11434` по OpenAI-совместимому API `/v3`.

Укажи реальный путь к модели. OVMS endpoint для Chat Completions имеет вид `http://127.0.0.1:11434/v3/chat/completions`.


## Доступные MCP-инструменты

| Инструмент | Назначение |
| --- | --- |
| `get_project_structure` | Возвращает дерево проекта с ограничением глубины. |
| `get_project_file` | Читает файл; по умолчанию возвращает до 200 строк. |
| `create_conftest_file` | Генерирует и сохраняет `conftest.py`; контекст проекта передаётся через `project_context`. |
| `create_api_test` | Обязательно читает `pytest.ini`, генерирует тесты и сохраняет Pydantic-схемы в `schemas.py` рядом с тестом, если путь не задан отдельно. |
| `refactor_text` | Возвращает переработанный текст по инструкциям, не записывая файл. |
