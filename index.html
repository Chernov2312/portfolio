О себе

Backend-разработчик на Python. Строю асинхронные API на FastAPI, пишу бизнес-логику на Django, выношу фоновые задачи в Celery + Redis. Работаю с SQLAlchemy и PostgreSQL, упаковываю сервисы в Docker / docker-compose, настраиваю CI/CD на GitHub Actions и покрываю код тестами на pytest. В портфолио — веб-мессенджер с ИИ-функциями, MCP-сервер для генерации тестов с локальной моделью, сервис доставки вебхуков, чат с GigaChat, сервис бронирования переговорок и другие проекты. Участвую в разработке командного прототипа AI-buddy — помощника для онбординга стажёров.

📨 Webhook Relay Service — сервис доставки вебхуков
README · Webhook Relay Service · GitHub · webhook_relay_service
  • Приём событий через HTTP API, сохранение в PostgreSQL и асинхронная доставка зарегистрированным получателям через Celery / Redis; постановка события в очередь возвращает 202 и event_id.
  • Подпись каждого исходящего запроса с помощью HMAC-SHA256 по точным байтам JSON; секрет получателя возвращается только при регистрации.
  • До трёх общих попыток доставки при временных сетевых ошибках, ответах 5xx и 429, с паузами 2 и 4 секунды; постоянный 4xx завершает доставку сразу.
  • API для просмотра статуса события и всех попыток доставки, проверка PostgreSQL и Redis через /health, документация Swagger UI.
  • Docker Compose, автоматическое применение миграций Alembic при старте API; проверки на pytest и Ruff.

🤝 AI-buddy — помощник стажёра в онбординге
README · AI-buddy · GitHub · ai-buddy
  • Командный прототип для Hack&Change 2026, в разработке. Помощник стажёра Авито: план адаптации, чат и помощь наставника.
